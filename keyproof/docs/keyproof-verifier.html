K KeyProof Verifier

Check a KeyProof proof

Drop the keyproof-proof-….json file a tenant or landlord gave you. Everything is checked in this browser, against KeyProof's official verification key and trusted-issuer list built into this page – nothing is uploaded, and the file cannot vouch for itself.

Independent check with the open-source tool: save proof, publicSignals and the verification key from the file, then run snarkjs groth16 verify verification_key.json public.json proof.json.
